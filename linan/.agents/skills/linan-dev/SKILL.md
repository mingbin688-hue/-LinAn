# 邻安开发

读取项目根 `AGENTS.md` 和本次需求涉及的实际入口。沿用现有风险引擎、鉴权和任务状态机；业务约束见根指令，不复制到新框架。

先确定可观察的目标行为与接口。跨前后端工作时，主 Agent 先明确请求与响应，再按独立文件范围委派给 `linan-backend`、`linan-frontend`；需要独立验收时使用 `linan-verifier`。小改动可直接完成，不必固定启动所有角色。主 Agent 集成结果，避免共享文件同时写入。

针对行为变化补齐有意义的测试，并通过 `Verify.ps1 -BackendOnly` 或 `-FrontendOnly` 做针对性验证；交付前执行适用的完整检查。验证脚本及模型配置说明见 `docs/AGENT_WORKFLOWS.md`。

交接需说明最终行为、接口或迁移变化、已执行验证、未验证事项。保持用户数据库与当前服务；网络模型调用、打包和桌面/Android 验收使用项目提供的隔离入口。
