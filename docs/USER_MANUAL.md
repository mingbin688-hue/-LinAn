# 用户手册与答辩演示脚本

客户端没有独立的外观开关：界面跟随 Windows 的浅色/深色设置自动切换，切换系统主题后无需重启客户端。

## 社区管理员

守护总览显示当前老人、待关注事件、任务和可用人员。数据不可用单独保留；老人档案支持建立、编辑、搜索与查看，新档案不会自动获得成熟基线。

信息上报可记录活动窗口、未报平安、未能联系、需要帮助或数据离线。外出、在家、休息确认有效期为1—24小时。外出反馈作为上下文，已打开的高等级事件仍需复核。

任务中心点击“计算派单建议”，逐条查看推荐人员和仿真到达时间。调整人选必须写理由。推荐超过五分钟，或任务、人员出现相关变化时重新计算。已派单、已接单、处理中占用人员容量；待复核释放执行容量。拒单回到待确认，可结合原因更新人员状态后重新计算。

关注事件的核实请求超过十分钟未得到回应时升级优先。内置处置时限：紧急2分钟、优先10分钟、关注30分钟、数据核查10分钟。超时提醒每个阶段发一次，状态变化后重新计时。这些是演示参数，不是实际照护标准。

已确认安全或已核查的数据问题可以关闭；未联系到或仍需帮助必须继续跟进。管理员也可以协助接单与处置，操作账号会如实记录。

“设置”页用于接入云端大模型：填写兼容 OpenAI 的基础地址、模型名称和 API Key，先测试连接再保存。模型名称可以点“从服务商获取模型”从下拉列表搜索选择，也可以手动填写。密钥保存在本机数据库，页面只显示尾号；关闭启用开关即回到规则模式，模型不会改变风险等级或执行派单。

## 照护人员、家属与老人

`staff1`—`staff4` 仅看到自己的任务与当前关联老人。接单 → 开始处理 → 提交结果；拒单说明原因。自己的人员页面可修改值班、是否接受新任务、仿真所在楼栋。

`family` 和 `elder` 只关联王桂兰。手机端“我很平安”补充报平安；“请联系我”生成联系需求；“我需要帮助”确认后生成紧急事件。外出、在家、休息可补充上下文。当前演示使用站内消息，不会拨打电话或发送短信。

## 回放与实验

三人情景为王桂兰未报平安、李建国活动偏离、张秀英主动求助。未关闭同类异常合并，并保留新证据。资源冲突情景增加其他老人的求助，验证等待和容量约束。

CASAS回放将选定虚拟档案用于展示同一个公开单住户的测试窗口，并更新其基线来源；不代表数据真实来自该虚拟人物，也不证明多老人泛化。原始时间保留，演示观察时间映射到当前时刻；同一老人重复回放相同原始窗口时去重。

运行对比实验会实际计算并保存在数据库，显示合成活动、公开活动和社区调度结果。导出结果得到JSON，导出已复核反馈用于人工复盘。离线训练不自动替换在线模型。

## 建议的六分钟答辩顺序

| 时间 | 操作与讲述重点 |
|---|---|
| 0:00—0:40 | 管理员总览：先关注谁、安排谁、是否解决 |
| 0:40—1:30 | 三人情景与判断依据，区分风险和数据缺失 |
| 1:30—2:20 | 推荐的技能、占用、到达时间；修改人员状态，演示旧推荐被拦截 |
| 2:20—3:30 | 确认派单，切换对应照护人员，接单、处理、反馈 |
| 3:30—4:20 | 管理员复核关闭，展示快照、负责人、时间和人工调整 |
| 4:20—5:10 | CASAS回放与实际实验，解释召回率局限和调度等待代价 |
| 5:10—6:00 | 手机老人端、家属权限，以及社区访谈和独立验证的下一步 |

## Windows 与 Android 客户端

同一套 Flutter 代码构建 Windows 与 Android 客户端：Windows 运行 `app/build/windows/x64/runner/Release/linan_app.exe`；Android 安装 `app/build/app/outputs/flutter-apk/app-release.apk`。Windows 客户端默认连接 `http://127.0.0.1:8765`，Android 模拟器默认连接 `http://10.0.2.2:8765`，登录页的“服务器地址”可改为局域网 IP。跨设备演示时让手机与电脑处于同一局域网，并允许防火墙访问。开发调试时后端用 `Start.ps1 -Background` 启动，客户端用 `flutter run -d windows` 热重载。
